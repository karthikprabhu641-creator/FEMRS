# Expiry Saathi

Offline-first expiry tracking PWA for local shops.

## Development

Use the pinned Node.js version in `.node-version` and pnpm 12.21.0:

```sh
corepack pnpm install
corepack pnpm dev
```

Quality checks:

```sh
corepack pnpm typecheck
corepack pnpm lint
corepack pnpm test
corepack pnpm build
```

The app is currently a project shell. Product/domain features are tracked milestone by milestone in [docs/ROADMAP.md](./docs/ROADMAP.md).
